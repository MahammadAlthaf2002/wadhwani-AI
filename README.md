# 🌟 Wadhwani AI - Multilingual Social Impact Platform

An AI-powered public social welfare web application serving **Primary Healthcare**, **Smallholder Farmers**, and **Out-of-School Students** across India with high-precision vernacular AI models, voice assistants, and clinical medicine verification.

---

## 🚀 Quick Start in VS Code

Open this folder in **VS Code**:
```bash
# 1. Open the project folder in terminal or VS Code
cd "c:\Users\Althaf Syed\Desktop\Wadhwani AI project code"

# 2. Install dependencies (if not already installed)
npm install

# 3. Start the Vite React Frontend (Port 5175)
npm run dev

# 4. In a second terminal, start the Backend Server (Port 5001)
npm run server
```

Open your browser at: **`http://localhost:5175/`**

## 🎓 Student Exam & Level-Up Curriculum
- Step-by-step learning from scratch for children unable to attend school.
- Grade Levels: Foundational (Classes 1–3), Primary (Classes 4–5), Middle (Classes 6–8), Secondary Board Prep (Classes 9–10).
- Pure academic subjects: **Mathematics**, **Science**, **Social Studies**, and **English**.
- Daily audio lessons, interactive practice exams, and daily homework tasks.

## 🎙️ Live Vernacular Voice Assistant
- 24x7 voice calling in 7 Indian languages: English, Hindi, Telugu, Marathi, Kannada, Tamil, and Urdu.
- Speech-to-text and text-to-speech for uneducated or illiterate users.
- Built-in emergency guardrails with direct 104 National Health Helpline and 108 Emergency Ambulance buttons.
